# 06 — الهوية البصرية والأداء (Identity & Performance)

## الهوية البصرية

- **الشعار الحالي:** أيقونة منزل SVG مضمّنة داخل الهيدر (مربّع أزرق `#0D6EA8` + منزل أبيض + سقف أخضر `#12AD2B` + نقطة حمراء `#D7141A` = ألوان علم جيبوتي)، مع نص «Place-dj».
- **حزمة الهوية** (`identity/phase-01-place-logo`): **مقترحات غير معتمدة**. ينصّ `README.md` صراحةً: «لم يُعتمد أي مقترح نهائيًا». الاتجاهات الثلاثة: 01 Wordmark + Djibouti، 02 Modular Destination، 03 Portal / Open Place.
- **القرار:** **إبقاء الشعار الحالي** — التزامًا بقاعدة «لا تُعِد بناء الهوية» + كون الحزمة غير معتمدة رسميًا. استبداله بمقترح غير معتمد سيكون إعادة تصميم غير مبرَّرة.
- **الألوان:** القالب يستخدم بالفعل لوحة الحزمة المحدّثة (أزرق `#0D6EA8`، داكن `#084A72`، خلفية `#F3F7FA`، حدود `#DBE4EA`). الذهبي `#C9962B` يظهر كعنصر إبراز محدود.
- **التغيير المُنفّذ:** أُعيد ضبط الـ **favicon** ليطابق **الشعار المرئي** (منزل) بدل حرف «P» — لتحقيق اتساق الهوية المرئية مع أيقونة الموقع.
- **اتساق الهوية مع بيانات SEO:** `og:site_name='Place-dj'`، `<title>` يحمل «Place-dj»، favicon بهوية الموقع → متسقة.
- **قرار خارجي مطلوب:** اعتماد أحد اتجاهات الحزمة (02/03) رسميًا إن رغب المالك، مع فحص العلامة التجارية.

## الأداء

- **تحميل كسول** `loading="lazy"` على صور البطاقات (بما فيها البطاقات المشابهة).
- **حاويات بأبعاد ثابتة** `aspect-ratio` (4/3 للبطاقات، 16/10 للمعرض) → لا إزاحة تخطيط عند تحميل الصور.
- **مصغّرات** عبر `resizeImage(data:post.featuredImage, 900, "4:3")` لصور البطاقات بدل الصور الكاملة.
- **تأخير الإدخال (debounce 220ms)** للبحث النصي/الرقمي؛ التحديث الفوري للقوائم المنسدلة.
- **لا مكتبات JS/CSS خارجية ضخمة** — الأيقونات SVG مضمّنة بدل مكتبات أيقونات؛ لا طلبات بيانات مكرّرة (طلب تغذية واحد للبطاقات المشابهة).
- **ملاحظة صريحة:** **لا ادّعاء بتحسين Core Web Vitals** — لم يُقَس فعليًا. الإجراءات أعلاه ممارسات معروفة فقط.
