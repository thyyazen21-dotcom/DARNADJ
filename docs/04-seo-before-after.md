# 04 — SEO: قبل / بعد (DARNADJ → Place-dj)

> المصدر: `live_home.html` + `live_post.html` (قبل) مقابل `theme-PLACE-DJ.working.xml` (بعد).
> النطاق **لم يتغيّر**: `shershar.blogspot.com`. لم تُنفّذ أي هجرة نطاق.

## 1) العلامة والعنوان

| العنصر | قبل | بعد | النوع |
|---|---|---|---|
| عنوان المدونة (إعداد Blogger) | «بلاس» | «بلاس» (لم يُغيَّر) | **خارجي** |
| `<title>` (منشور) | `بلاس: فيلا شاطئية للإيجار` | `فيلا شاطئية للإيجار — Place-dj` | داخل القالب |
| `<title>` (الرئيسية) | `بلاس` | `Place-dj — منصة تأجير العقارات في جيبوتي` | داخل القالب |
| `og:site_name` | غير موجود | `Place-dj` | داخل القالب |
| `og:locale` | غير موجود | `ar` | داخل القالب |

## 2) العلامات المكرّرة (Duplicates) — تم إصلاحها

| العنصر | قبل | بعد |
|---|---|---|
| `og:title` | **مرّتان** (all-head-content + القالب) | **مرّة واحدة** (all-head-content) |
| `og:url` (رئيسية) | **مرّتان** | **مرّة واحدة** |
| `og:url` (منشور) | **مرّتان**: صحيحة + **فارغة** | **مرّة واحدة صحيحة** |
| `canonical` (منشور) | **مرّتان** | **مرّة واحدة** |
| `theme-color` | **مرّتان** (فارغة + `#0d6ea8`) | **مرّة واحدة** (`#0d6ea8`) |

**السبب الجذري:** القالب كان يعيد تعريف `og:title`/`og:url`/`canonical` رغم أن `all-head-content` يُصدرها أصلًا، و`data:post.url` غير متاح في `<head>` (لا حلقة منشورات) فأنتج `og:url` فارغًا.

## 3) Schema.org

| العنصر | قبل | بعد |
|---|---|---|
| `mainEntityOfPage` (منشور) | `<!--Can't find substitution for tag [post.url]-->` | `<data:blog.canonicalUrl/>` (صحيح) |
| `WebSite` / `Organization` | موجود | موجود (كما هو) |
| تقييمات وهمية / `RealEstateAgent` | غير موجودة | **لم تُضَف** (لا ادّعاءات غير حقيقية) |

## 4) hreflang

| قبل | بعد |
|---|---|
| `https://www.place-dj.com/` (**نطاق خاطئ**) | `data:blog.homepageUrl` (يُنتج `shershar.blogspot.com`) |

## 5) robots / canonical / قابلية الفهرسة

- **لم يُضَف أي `noindex`**. لم يُكسَر `canonical` (يبقى من `all-head-content`).
- لا تغيير في بنية الروابط أو عناوين المنشورات.

## 6) عناصر أخرى

| العنصر | قبل | بعد |
|---|---|---|
| `twitter:card` | `summary_large_image` | `summary_large_image` (كما هو) |
| `favicon` | غير موجود | أيقونة SVG بهوية Place-dj (`#0D6EA8` + `#C9962B`) |
| `og:type` | `website` دائمًا | `article` للمنشورات / `website` لغيرها |
| `description` | موجود | موجود (كما هو) |

## 7) إجراءات خارجية مطلوبة (خارج القالب)

1. **إعدادات Blogger:** تغيير عنوان المدونة من «بلاس» إلى «Place-dj» — لأن `og:title` في الرئيسية يُصدره `all-head-content` من إعداد عنوان المدونة ولا يمكن تجاوزه من القالب دون إنشاء علامة مكرّرة.
2. **Google Search Console:** إرسال/تحديث خريطة الموقع (sitemap) بعد النشر (إن لم تكن مُرسَلة).
3. **النطاق:** يبقى `shershar.blogspot.com` (لا إجراء).

## 8) عناصر أُبقيت كما هي (حفاظًا على الفهرسة)

- `canonical` لكل صفحة (من `all-head-content`).
- عناوين المنشورات الأصلية.
- روابط المنشورات والصور والتسميات.
- `robots` الافتراضي لـ Blogger (لا منع فهرسة).
