# DARNADJ — Sample Content (12 posts)

ملف محتوى جاهز لـ **12 مشاركة عقارية** مطابق لـ «قالب المخرج» (قوالب AR/EN/FR) ولقواعد
الأسعار في ثيم Blogger (`IMPORT_THIS_THEME.xml`).

## الملفات
| الملف | الوصف |
|------|-------|
| `DarnaDJ_12_Posts_Content_AR.html` | **الملف الرئيسي**: عرض منسّق (RTL) لكل مشاركة مع العنوان، التسميات، الصور، وكود HTML كامل جاهز للنسخ. |
| `DarnaDJ_12_Posts_Content.csv` | جدول منظّم (رقم العقار، العنوان، المنطقة، النوع، السعر، التسميات، روابط الصور، وكود HTML). |
| `DarnaDJ_12_Posts_Content.json` | نفس البيانات بصيغة JSON (لأي أتمتة/استيراد). |
| `images/` | 36 صورة افتراضية (JPEG) — 3 صور لكل عقار (نسخ محلية احتياطية). |

## طريقة الاستخدام في Blogger
1. مشاركة جديدة ← اكتب **العنوان** من الجدول.
2. بدّل المحرر إلى **«عرض HTML»** والصق **كود المشاركة** كما هو.
3. أضف **التسميات (Labels)** كما هي في حقل التسميات (مفصولة بفواصل).
4. انشر. أول صورة في الكود تصبح **الصورة البارزة** تلقائيًا، وبقية الصور تظهر في **المعرض**.

## قاعدة السعر (تُحتسب مرة واحدة فقط)
- `price:1000` → السعر **الأساسي قبل الرسوم** → المعروض = 1000 × 1.10 = **1100**.
- `pricefinal:1650` → السعر **شامل الرسوم مسبقًا** → يُعرض **كما هو** (دون أي زيادة).
- `cur:USD` → العملة (الافتراضي USD).
- `per:month` → وحدة التسعير (`night` | `day` | `week` | `month` | `stay`).
- إذا رفض Blogger الرمز `:` في التسميات، استبدله بـ `-` (مثال `price-1000`); القالب يدعم الفواصل `:` و`-` و`_`.
- عند غياب/فساد السعر يظهر للعميل تنبيه «⚠ بيانات السعر غير مكتملة» بدل سعر وهمي أو صفر.
