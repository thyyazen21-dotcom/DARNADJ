# DARNADJ — Sample Content (12 posts)

ملف محتوى جاهز لـ **12 مشاركة عقارية** مطابق لـ «قالب المخرَج» (قوالب AR/EN/FR) ولقواعد
الأسعار في ثيم Blogger (`IMPORT_THIS_THEME.xml`).

## الملفات
| الملف | الوصف |
|------|-------|
| `DarnaDJ_12_Posts_Content_AR.html` | **الملف الرئيسي**: عرض منسّق (RTL) لكل مشاركة مع العنوان، التسميات، الصور، وكود HTML كامل جاهز للنسخ. |
| `DarnaDJ_12_Posts_Content.csv` | جدول منظّم (رقم العقار، العنوان، المنطقة، النوع، الغرف، الحمامات، المطابخ، المساحة، الحالة، السعر، التسميات، روابط الصور، وكود HTML). |
| `DarnaDJ_12_Posts_Content.json` | نفس البيانات بصيغة JSON (لأي أتمتة/استيراد). |
| `sample_posts_html/` | **12 ملف HTML منفصل** — كل ملف يحتوي كود مشاركة واحدة جاهزًا للصق في محرر Blogger (وضع HTML). هذه ملفات لصق داخل مشاركة، وليست ملف استيراد للقالب. |
| `images/` | 36 صورة افتراضية (JPEG) — 3 صور لكل عقار (نسخ محلية احتياطية). |

## طريقة الاستخدام في Blogger
1. مشاركة جديدة ← اكتب **العنوان** من الجدول.
2. بدّل المحرر إلى **«عرض HTML»** والصق **كود المشاركة** (من `sample_posts_html/` أو من الملف الرئيسي) كما هو.
3. أضف **التسميات (Labels)** كما هي في حقل التسميات (مفصولة بفواصل).
4. انشر. أول صورة في الكود تصبح **الصورة البارزة** تلقائيًا، وبقية الصور تظهر في **المعرض** (سلايدر البطاقة وصفحة التفاصيل).

## التسميات المنظّمة (Labels)
### السعر (تُحتسب الرسوم مرة واحدة فقط)
- `price:1000` → السعر **الأساسي قبل الرسوم** → المعروض = 1000 × 1.10 = **$1,100**.
- `pricefinal:1100` → السعر **شامل الرسوم مسبقًا** → يُعرض **كما هو** (دون أي زيادة).
- `cur:USD` → العملة (الافتراضي USD). مثال العرض: `$1,100`.
- `per:month` → وحدة التسعير (`night` | `day` | `week` | `month` | `stay`). مثال العرض: `$1,100 / شهر`.
- إذا رفض Blogger الرمز `:` في التسميات، استبدله بـ `-` (مثال `price-1000`)؛ القالب يدعم الفواصل `:` و`-` و`_`.
- **عند غياب/فساد السعر** لا يُعرض سعر وهمي ولا صفر، **ولا تظهر أي رسالة إدارية للعميل**؛ يُترك حقل السعر فارغًا فقط.

### المواصفات والحالة (تُعرض في البطاقة وصفحة التفاصيل)
- `beds:2` → عدد غرف النوم.
- `baths:1` → عدد الحمامات.
- `kitchens:1` → عدد المطابخ.
- `sqm:95` → المساحة بالمتر المربع.
- `status:متوفر` أو `status:غير متوفر` أو `status:للإيجار` أو `status:للبيع` → **شارة الحالة المرئية**.
- التسميات النصية العادية (مثل `شقة مفروشة`، `جيبوتي المدينة`، `للإيجار`) تُقرأ أيضًا للتصفية والبحث.
